# pygame

Game programming lessons using [pygame](https://www.pygame.org). Games that come in parts build on
the previous part.

```
pip install pygame
python pong_part1.py
```

| file | what it is |
|---|---|
| `starter_code.py` | Empty window and game loop to start from |
| `pong_part1.py` | Two-player Pong |
| `pong_part2.py` | Pong with a win condition and restart |
| `flappybird_part1.py` | Flappy Bird |
| `spaceinvaders_part1.py` | Space Invaders |
| `clicker.py` | Clicker game |
